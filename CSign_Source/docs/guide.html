📖 Hướng dẫn CSign

📱 Giới thiệu CSign

CSign là một công cụ mạnh mẽ dành cho iOS, cho phép bạn dễ dàng ký các ứng dụng IPA trực tiếp trên thiết bị của mình mà không cần máy tính. Với giao diện hiện đại và trực quan, CSign mang đến trải nghiệm tuyệt vời cho người dùng.

⬇️ Cách cài đặt

Bạn có thể cài đặt CSign thông qua các phương pháp sau:

  • TrollStore: Khuyên dùng. Tải file IPA của CSign và cài đặt trực tiếp qua TrollStore để không bị thu hồi chứng chỉ.
  • Sideloading: Sử dụng các công cụ như Sideloadly, AltStore, hoặc Scarlet để cài đặt CSign bằng chứng chỉ nhà phát triển hoặc chứng chỉ miễn phí (có thời hạn 7 ngày).

🔑 Nhập chứng chỉ

Để bắt đầu ký ứng dụng, bạn cần thêm chứng chỉ vào CSign:

  1. Vào mục Cài đặt -> Quản lý chứng chỉ.
  2. Nhấn nút Thêm chứng chỉ (dấu +).
  3. Bạn có thể chọn nhập từng file (.p12 và .mobileprovision) hoặc nhập từ file ZIP chứa cả hai.
  4. Nhập mật khẩu của chứng chỉ và nhấn Lưu.

✍️ Ký ứng dụng IPA

Quá trình ký ứng dụng rất đơn giản:

  1. Vào tab Ký ứng dụng.
  2. Chọn file IPA mà bạn muốn cài đặt.
  3. Chọn chứng chỉ bạn đã thêm ở bước trước.
  4. Tùy chỉnh cấu hình (nếu cần) như Đổi tên, Đổi Bundle ID.
  5. Nhấn Bắt đầu ký. Sau khi hoàn tất, bạn có thể cài đặt ngay lập tức.

💉 Tiêm Tweak

CSign hỗ trợ tiêm các file dylib, deb vào ứng dụng của bạn:

  1. Trong màn hình thiết lập ký, cuộn xuống phần Thư viện (Dylibs/Frameworks).
  2. Thêm các file .dylib hoặc .deb mà bạn muốn tiêm.
  3. Tiến hành ký như bình thường, các tweak sẽ được tích hợp vào IPA.

🌐 Cài đặt máy chủ ký

CSign cho phép bạn thiết lập máy chủ ký (Sign Server) để tạo link cài đặt qua trình duyệt (OTA):

  • Đi tới phần Cài đặt -> Máy chủ.
  • Khởi động máy chủ cục bộ.
  • Bạn có thể quét mã QR hoặc truy cập đường link để cài đặt app ngay từ Safari.
